## 📋 نظرة عامة

**وصلة** منصة تسويق بالعمولة تربط التجار بالمسوقين والعملاء في مسار واضح وقابل للقياس. كل رابط واضح، كل طلب قابل للتتبع، وكل عمولة مبنية على سجل مفهوم.

### 🎯 القيمة المقترحة

| الطرف | القيمة |
|-------|--------|
| **التاجر** | وسّع مبيعاتك عبر شبكة مسوقين. كل رابط واضح، وكل طلب قابل للتتبع. |
| **المسوّق** | سوّق منتجات موثوقة، وتابع عمولتك بوضوح. كل عمولة مبنية على سجل مفهوم. |
| **العميل** | تجربة شراء واضحة مع معلومات موحدة عن المنتج والتوصيل والإرجاع. |
| **المنصة** | دخل من رسوم المبيعات وبيانات تشغيل تساعد على تحسين المطابقة. |

### الخطوط

- **العربية الأساسية**: Noto Sans Arabic (عناوين وواجهات ونصوص طويلة)
- **الإنجليزية والأرقام**: Inter (تسميات المنتج، أرقام الطلبات، لوحات المؤشرات)

### الشعار

الشعار يتكون من:
- حلقتين متصلتين ترمزان إلى الصلة بين التاجر والمسوق والعميل
- سهم ذهبي يرمز إلى انتقال المنتج والزيارة إلى خطوة تالية قابلة للقياس
- الكحلي يمثل الثقة والثبات، والتركواز يضيف طاقة رقمية ونمواً

## 🏗️ البنية التقنية

### الصفحات الرئيسية

1. **الصفحة الرئيسية** (`LandingPage.tsx`)
   - عرض القيمة المقترحة
   - شرح آلية العمل
   - دورة حياة العمولة

2. **بوابة التاجر** (`MerchantDashboard.tsx`)
   - إدارة المنتجات والمخزون
   - متابعة الطلبات والعمولات
   - إحصائيات المبيعات والتسليم

3. **بوابة المسوّق** (`MarketerDashboard.tsx`)
   - كتالوج المنتجات
   - إنشاء روابط الإحالة
   - متابعة الأرباح والسحب

4. **لوحة الإدارة** (`AdminDashboard.tsx`)
   - إدارة الحسابات والمنتجات
   - مراقبة العمولات والسحوبات
   - سجل التدقيق والشكاوى

5. **صفحة المنتج** (`ProductPage.tsx`)
   - تفاصيل المنتج
   - أدوات التسويق والمشاركة
   - قواعد الإسناد

6. **صفحة تسجيل الدخول** (`LoginPage.tsx`)
   - اختيار نوع الحساب
   - تسجيل دخول/إنشاء حساب

### نموذج البيانات

```typescript
// الحالات الرئيسية
type CommissionState = 'pending' | 'approved' | 'payable' | 'paying' | 'paid' | 'cancelled_reversed' | 'held_review';
type OrderStatus = 'new' | 'confirmed' | 'preparing' | 'out_for_delivery' | 'delivered' | 'cancelled' | 'delivery_failed' | 'returned';
type ProductStatus = 'draft' | 'pending_review' | 'published' | 'rejected' | 'stopped' | 'out_of_stock';

// اللقطات المالية (لا تتغير بعد إنشاء الطلب)
interface Order {
  priceSnapshot: number;      // سعر المنتج وقت الطلب
  commissionSnapshot: number; // العمولة وقت الطلب
  commissionBasisSnapshot: string; // قاعدة الحساب
}
```

## 🔄 دورة حياة العمولة

```
┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│   معلقة     │───▶│   معتمدة    │───▶│   مستحقة    │
│  (pending)  │    │ (approved)  │    │ (payable)   │
└─────────────┘    └─────────────┘    └─────────────┘
                                              │
                                              ▼
┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│   مدفوعة    │◀───│  قيد الدفع  │◀───│   مستحقة    │
│   (paid)    │    │  (paying)   │    │ (payable)   │
└─────────────┘    └─────────────┘    └─────────────┘

حالات خاصة:
- ملغاة/معكوسة (cancelled_reversed): عند الإرجاع أو الإلغاء
- موقوفة للمراجعة (held_review): عند الاشتباه أو النزاع
```

## 🛡️ قواعد الإسناد

### TRACK-01 إلى TRACK-08

1. **TRACK-01**: رمز إحالة فريد غير قابل للتخمين
2. **TRACK-02**: تسجيل بيانات النقرة لأغراض القياس ومكافحة الاحتيال
3. **TRACK-03**: حفظ رمز الإحالة بشكل خادمي موقّع
4. **TRACK-04**: نافذة الإسناد 30 يوماً (آخر نقرة صالحة)
5. **TRACK-05**: الإحالة على مستوى التاجر
6. **TRACK-06**: تثبيت هوية المسوق داخل سجل الطلب
7. **TRACK-07**: دعم طلبات الهاتف/واتساب عبر كوبونات
8. **TRACK-08**: تسجيل الحالات المشتبه بها للمراجعة

## 📊 مؤشرات الأداء الرئيسية

| المؤشر | التعريف |
|--------|---------|
| **GMV** | إجمالي قيمة الطلبات قبل استبعاد الإلغاء والمرتجعات |
| **صافي المبيعات المؤهلة** | قيمة المنتجات المسلّمة غير الملغاة وغير المرتجعة |
| **معدل التحويل** | عدد الطلبات ÷ عدد النقرات الصالحة |
| **معدل التسليم** | عدد الطلبات المسلّمة ÷ الطلبات المؤكدة |
| **معدل الإرجاع** | الطلبات المرتجعة ÷ إجمالي الطلبات |
| **أرباح المسوق** | العمولات المعتمدة أو المستحقة أو المدفوعة |
| **إيراد المنصة** | رسوم المنصة المستحقة على الطلبات المؤهلة |

## ✅ معايير القبول

- [x] **AC-01**: رابط الإحالة يحتوي على رمز فريد ولا يكشف بيانات شخصية
- [x] **AC-02**: فتح الرابط يُسجل النقرة ولا يمكن تزوير قيمة الإحالة
- [x] **AC-03**: إكمال الطلب ضمن نافذة الإسناد يُظهر هوية المسوق
- [x] **AC-04**: الطلب بدون إحالة لا يُسند إلى مسوق افتراضي
- [x] **AC-05**: لقطة السعر والعمولة محفوظة عند الطلب
- [x] **AC-06**: إلغاء الطلب قبل التسليم يمنع اعتماد العمولة
- [x] **AC-07**: الإرجاع الجزئي يحسب العمولة على الكمية المؤهلة فقط
- [x] **AC-08**: لا يمكن دفع سحب أكبر من الرصيد المتاح
